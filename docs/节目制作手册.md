# AI 麻将室 · 节目制作手册

> 把「多个不同模型 AI 公平打立直麻将」做成可直播、可录制、有解说的节目。
> 本手册覆盖从跑对局到出片的完整流程。所有命令在项目根目录下执行。

---

## 0. 概览

```
RiichiEnv 引擎(裁判, 强制公平/完整规则)
   └─ room.py 对局循环：每席一个 Agent(random / mock / LLM)
        └─ 事件溯源落盘：game.mjai.jsonl(上帝视角全量) + decisions.jsonl(每席推理) + summary.json
             ├─ replay.py 确定性回放 → web/ 上帝视角 viewer(四家明牌+推理面板+解说字幕)
             │     ├─ OBS Browser Source → RTMP → Bilibili/Twitch  【直播, 含解说音频】
             │     └─ record_game.py(Playwright) → WebM            【无人值守录制, 仅视频】
             ├─ tournament.py 复式座位轮换锦标赛 → leaderboard.html 积分榜
             └─ make_commentary.py → 解说文本 + SRT + edge-tts MP3
```

**关键设计**：
- **公平靠引擎**：每个 Agent 只拿到本席手牌 + 场上明牌（牌河/副露/宝牌），引擎枚举合法动作，非法输出自动兜底。
- **一份数据多用**：MJAI JSONL 同时服务公平审计、回放、直播、录制、统计。
- **解说 facts-first**：解说词只来自引擎事件 + Agent 自己记录的推理，不编造事实。
- **素材合规**：牌面为自绘 SVG（CC0），无外部版权素材，直播无需换美术。

## 2. 跑对局 / 跑锦标赛

### 单局
```powershell
# 4 个随机 agent（无需密钥，秒级）
.\.venv\Scripts\python.exe server\run_game.py --config config/agents.random.json --seed 42
# 真实模型（2 LLM + 2 random，约 15–20 分钟）
.\.venv\Scripts\python.exe server\run_game.py --config config/agents.real.json --seed 42 --out runs/p1_real_full
```
产物落在 `runs/<game_id>/`：`game.mjai.jsonl` + `decisions.jsonl` + `summary.json`。

### 锦标赛（复式座位轮换 + 积分榜）
```powershell
.\.venv\Scripts\python.exe server\run_tournament.py --config config/tournament.random.json --name 测试杯
# 真实多模型锦标赛（节目用；四席不同模型）
.\.venv\Scripts\python.exe server\run_tournament.py --config config/tournament.real.json --name AI雀神杯 --verbose
```
- **复式**：同一副牌（seed）打 4 轮，每轮循环换座位（`seat s ← specs[(s+r)%4]`），消除牌运/座位偏差。
- **计分**：`placement`（顺位点 4/3/2/1）/ `botzone`（3/2/1/0）/ `tenhou`（90/45/0/-135）或点差。
- 产物：`runs/<name>/tournament.json` + `leaderboard.md` + 每局 `games/<game_id>/`。
- **样本量以节目好看为准**，不追求统计显著（几局~几十局即可）。

## 2b. 交互界面（人类 GUI / AI CLI / Skill）

### 人类：Web GUI 发起新对局
1. 打开 `http://127.0.0.1:18765`。
2. 顶栏点 **🎮新开一局** → 模态：
   - **逐席选人**：东/南/西/北 四个下拉，从**选手库**挑任意角色/模型（可四席不同模型，也可重复）；
   - **预设填充**：选一个 `config/*.json` 阵容一键填入四席，再逐席微调；
   - **seed**（同 seed 可复现/复式）、**局 id**（留空自动生成）；
   - 点 **开始直播** → POST `/api/live/start`（body 带 `seats`=4 个 roster id）→ 模态关闭并自动切到该局的 🔴LIVE 视图。
   - 模态下方列出**进行中的局**，点「加入观看」直接切过去。
3. **👥选手库** `/roster.html`：角色管理 CRUD（新建/编辑/删除/搜索/启用）。字段：显示名/ID/类型(llm/random/mock)/品牌/model/base_url/api_key_env/头像/temperature/timeout/人设/高级 JSON(extra_body、omit_temperature、max_retries)。角色形象与模型绑定解耦；`config/roster.json` 为唯一选手源。
4. 其余控件：播放/暂停/单步/scrub/倍速/暗牌/解说/声音；`?game=<id>` 回放、`?live=<id>` 直播。
5. 积分榜 `/leaderboard.html`：选手总榜 + 锦标赛榜 + 每局明细 + 进行中局「🔴观看直播」。

### AI：统一 CLI（解说员 / 主持人 Agent）
`scripts/room.py`，全部子命令支持 `--json` 机器可读：
```powershell
python scripts\room.py configs                 # 可用阵容（live/tournament + 四席模型）
python scripts\room.py roster                  # 选手库（角色+模型绑定）
python scripts\room.py new --seats qwen4-max-invite,deepseek-v4-1-flash,glm-5-3,deepseek-v4-pro --seed 7  # 逐席选人发起直播局
python scripts\room.py new --config config/agents.live2026.json --seed 7   # 或用预设阵容
python scripts\room.py new --config config/agents.mock.json --offline --out runs\x  # 离线跑
python scripts\room.py list                    # 已落盘局 + 进行中直播局
python scripts\room.py state --game <id>       # 当前帧数/状态/分数（了解局面）
python scripts\room.py watch --game <id>       # 打印观看 URL
python scripts\room.py standings               # 选手总榜
python scripts\room.py tournament --config config/tournament.show2026.json --out runs\cup
python scripts\room.py show --tournament runs\cup --record   # 一键节目产物
python scripts\room.py recap --game <id>       # 复盘 markdown
python scripts\room.py commentary --game <id> --tts          # 解说+配音
python scripts\room.py record --game <id>      # 录高光样片
```
主持人/解说工作流：`configs`→`new`→轮询 `state` 直到 done→`watch` 给人看→`recap`/`commentary`/`show` 出节目。详见 [skills/ai-mahjong-room/SKILL.md](../skills/ai-mahjong-room/SKILL.md)。

`skills/ai-mahjong-room/SKILL.md` 为 Agent Skills 格式（frontmatter name/description + 前置/CLI/HTTP/工作流/规则公平/合规/排障）。支持 skill 的 Agent 载入后即知道如何开局/观局/解说/出节目，无需读源码。

## 3. 上帝视角回放

```powershell
.\.venv\Scripts\python.exe server\serve_viewer.py --port 18765
# 浏览器打开 http://127.0.0.1:18765
```
- 顶栏选局；`🏆 积分榜` / `📺 直播/对局` 进 `/leaderboard.html`（积分榜置顶 + 对局列表自动刷新 + 进行中局「观看直播」）。
- **雀魂风零重叠布局**：四家分区居中（手牌/牌河 6 列/副露），每席彩色标识 + 听牌/向听/立直/和了徽章；center 显示局/本場/供託/**余牌**/宝牌指示/里宝（和了时）/当前事件/和了块（役种+番符+点数）；右侧四席推理面板（reason + 可展开原始输出/CoT + 延迟 + 兜底标记）。
- 时间线：播放/暂停（空格）、单步（←/→）、回开局、拖动、节奏（节目 4000 / 直播 2500 / 1500 / 700 / 300 / 80 ms/步）；底栏「暗牌 / 声音 / 解说」开关。
- **规则交互/分区/头像**：
  - **鸣牌窗口**：有人打牌后若可吃/碰/杠/荣和，center 弹出「鸣牌窗口」列出**仅合法**选项（chosen 高亮），注记「他家可见窗口开放」；响应者席显示「可鸣牌/鸣牌」徽章（他人知道有人可鸣但不知具体）。
  - **振听/听牌**：每席徽章「振听」（红，不能荣和）/「听牌」（金）/「N 向听」；听牌张为引擎核算（reliable_waits）。
  - **副露/牌河分离**：每席「副露」虚线托盘（吃碰杠放置区）与「牌河」6 列网格明确分区。
  - **角色头像+档案**：四席显示公认 AI 娘头像（**15 品牌**：DeepSeek/千问/Kimi/智谱/GPT/Claude/Gemini/Grok/Seed/MiniMax/Llama/Mistral/Perplexity/文心/JEV）；`config/profiles.json` 为档案源（display/color/bio/credit/license）+ `brand_aliases` 前缀回退（任意席位名都有头像）；`/api/profiles` 供前端读取；`scripts/build_avatars.py` 重建头像（自动圆心检测）。**许可见 §8**。
  - **选手总榜**：`/leaderboard.html` 顶部「🌐选手总榜」跨正式局聚合（自动含最新完局）；random/测试局已归档 `runs/_archive` 不入榜。
- **固定布局/立直/四角头像**：
  - **固定坐标棋盘**：1500×940 绝对定位 + 等比缩放（窗口变化只缩放不重排）；副露托盘/牌河/手牌槽位**恒定常显**（空=占位格），不随牌变化自动适配。
  - **立直四重呈现**：立直宣言牌横放 + 「立直/双立直」大字 callout + center 供託棒 + 身份卡「立直」徽章。
  - **四角大头像**：身份卡移棋盘四角、头像 56px、模型名整行不截断。
  - **每席旋转（雀魂朝向）**：侧家/上家的手牌/牌河/副露**整席旋转**（右 -90° / 上 180° / 左 +90°），牌躺在该玩家朝向，而非正立堆叠；与雀魂观战一致。
  - **头像库+Qwen4 邀测**：AI 娘头像库 **4→15 品牌**（每品牌 canon 二创 + `orig_*` 原创商业 fallback，共 30 张）；`brand_aliases` 前缀回退保证任意席位名都有头像。**Qwen 席位升级 Qwen4-max-invite**（qwen-latest-series-invite-1102·qweneval 邀测端点·`BAILIAN_INVITE_API_KEY`·关思考）。
- **URL 参数**（截图/直播/录制用）：
  - `?game=<id>&frame=<n>` 定位到某帧。
  - `?game=<id>&autoplay=1&pace=2500` 自动播放（直播/录制）。
  - `&hide=1` 暗牌模式（只看不到的牌背，玩家视角）；`&loop=1` 循环；`&commentary=0` 关解说；`&bannerpause=3000` 和了/流局停留毫秒。

## 4. 直播（OBS Browser Source → Bilibili/Twitch）

**这是带解说音频的首选节目路径**（OBS 会捕获 viewer 播放的解说 MP3）。

1. 启动 viewer：`serve_viewer.py --port 18765`。
2. OBS → 来源 `+` → **浏览器**（Browser Source）：
   - URL：`http://127.0.0.1:18765/?game=<id>&autoplay=1&pace=2500`
   - 宽 `1920` 高 `1080`；FPS `30`。
   - ✅ 勾选「通过 OBS 控制音频」（Control audio via OBS）——这样解说音频进直播。
   - ❌ **关闭**「不可见时关闭源」（Shutdown source when not visible）——保持播放/音频连续。
   - 自定义 CSS 可留空（页面已是 1920×1080 深色绿桌布，OBS 就绪）。
3. 音频：桌面音频可静音，只留浏览器源音频（解说）。需要背景音乐另加媒体源。
4. 推流：OBS 设置 → 直播 → 服务选 Bilibili/Twitch，填 RTMP 地址 + 串流密钥 → 开始推流。
5. 换局：改 URL 的 `game=` 或直接在页面顶栏选局（autoplay 会从头播）。

> 自动播放音频策略：viewer 用 `new Audio().play()`；OBS 浏览器源默认允许自动播放。若被拦，字幕仍会显示。

### 4b. 实时直播模式（边打边看，含实时思考）

回放模式播的是**已录好**的对局；实时模式则**边打边播**——Agent 每走一步，上帝视角与推理面板即时更新，适合直播「AI 正在思考/出牌」的现场感。

1. 启动 viewer：`serve_viewer.py --port 18765`（实时对局跑在该进程内）。
2. 开一场实时对局：
   ```powershell
   .venv\Scripts\python.exe scripts\start_live.py --config config/agents.real.json --seed 7
   ```
   打印 `watch: http://127.0.0.1:18765/?live=<id>`。
3. 浏览器 / OBS Browser Source 打开该 `?live=<id>` URL：顶栏显示 `🔴 LIVE · N 事件 · 进行中`，画面自动跟随最新一步；推理面板实时刷新各模型思路。
   - 「⏸ 暂停跟随 / ▶ 跟随直播」按钮可暂停跟随去回看前面几步；拖动时间线 likewise 取消跟随。
   - 对局结束自动变 `✅ 直播结束`，之后可像回放一样 scrub 整局。
   - **实时解说**：边打边生成 facts-first 解说词 + edge-tts 配音 + 底部字幕；底栏「声音」「解说」开关控制。OBS 勾「通过 OBS 控制音频」即可把实时解说播进直播。
4. API（供自定义导播/集成）：`POST /api/live/start`、`GET /api/live/list`、`GET /api/live/state?game=<id>&since=<n>`（增量帧 + `commentary[]`）。
5. 实时局结束后同样落盘 `runs/<id>/`，可再走解说/录制/复盘管线。
6. **返回进行中的局**：`/leaderboard.html` 的「直播 / 对局列表」5s 自动刷新，进行中的局显示「🔴 观看直播」直接跳回 `?live=<id>`；「仅显示正式对局」可过滤测试局。

> 实时解说音频由异步 TTS 生成，可能比字幕晚 1–2s（字幕即时、音频就绪即播）；超快进（random/闪回）时音频可能追不上，属正常。要完全同步的解说直播可用 §4 回放模式。

## 5. 录制

### A. 无人值守视频（Playwright，仅视频）
```powershell
# 完整一局（直播节奏 2500ms/步，约 60 分钟）
.\.venv\Scripts\python.exe scripts\record_game.py --game p1_real_full --pace 2500
# 快速样片（200ms/步，录 12 秒）
.\.venv\Scripts\python.exe scripts\record_game.py --game p1_real_full --pace 200 --max-seconds 12
```
- 输出 `runs/recordings/<game>_<ts>.webm`（1920×1080）。
- **注意**：Playwright 只录视频、**不含音频**。解说音频要么走 OBS（见下），要么后期 mux（见 §6）。
- `--headed` 显示窗口；`--hide` 暗牌；`--no-commentary` 关字幕；`--max-seconds N` 限时。

### B. 带解说的录制（OBS）
OBS 浏览器源（§4）+ OBS「开始录制」→ 得到含解说音频的 MP4/MKV。**做节目推荐这条**。

## 6. 解说（facts-first + edge-tts）

```powershell
# 生成解说文本 + SRT + 逐句 MP3（免费 edge-tts，中文多音色）
.\.venv\Scripts\python.exe scripts\make_commentary.py --game runs/p1_real_full --tts
```
- 产物 `runs/<game>/commentary/`：`commentary.json`（按 `event_pos`  keyed）+ `commentary.srt` + `line_NNN.mp3`。
- 触发点：开局 / 立直 / 杠 / 和了(自摸/荣和+点数) / 流局 / 终局排名 + 少量推理高光。
- 音色：旁白 `YunxiNeural`；四席分别 `Xiaoxiao / Yunyang / Xiaoyi / Yunjian`（按席区分）。
- **直播/录制时**：viewer autoplay 会自动按 `event_pos` 播放对应 MP3 + 显示字幕（OBS 捕获音频）。
- **后期 mux（自动配音，推荐）**：`scripts/mux_commentary.py` 用完整版 ffmpeg（`pip install imageio-ffmpeg` 自带，无需另装）把解说 MP3 **按 autoplay 时间轴（pace+banner 停顿）精确混入** Playwright 无声视频，输出 H.264 MP4：
  ```powershell
  .\.venv\Scripts\python.exe scripts\mux_commentary.py --game p1_real_full `
      --video runs/recordings/<game>_<ts>.webm --start-frame 395 --pace 1800 `
      --out runs/<game>_highlight_audio.mp4
  ```
  `--start-frame`/`--pace` 必须与录制时一致。`make_show.py --record` 会自动录片段并 mux 配音。也可用 `commentary.srt` 在剪辑软件手动对齐。

## 7. 完整节目流程（一期「AI 雀神杯」）

1. **配置选手**：编辑 `config/tournament.real.json`（4 个模型，`api_key_env` 指向 `.env`）。
2. **跑锦标赛**：`run_tournament.py --config config/tournament.real.json --name AI雀神杯 --verbose`。
3. **看积分榜**：`serve_viewer.py` → `/leaderboard.html?tourney=AI雀神杯`，截图做片头/排名榜。
4. **选精彩局**：从每局明细挑和了多/逆转/立直对决的局，记下 `game_id`。
5. **生成解说**：`make_commentary.py --game runs/AI雀神杯/games/<game_id> --tts`。
6. **录制/直播**：OBS 浏览器源 `?game=<game_id>&autoplay=1&pace=2500` → 录制（含解说）或推流。
7. **后期**：剪掉冗长流局、加片头片尾/积分榜/BGM，导出上传 Bilibili。

- **密钥安全**：`.env` 已 gitignore；切勿把密钥写进配置入库或截图泄露。
- **规则**：天鳳默认立直规则（赤宝牌、立直、役满、振听、流局等由引擎裁决）；边角规则未逐行人工审计，以引擎为准。
- **公平**：Agent 物理上拿不到他家手牌；非法/超时输出回退合法动作并记录（`fallback` 标记，可在推理面板看到）。

## 9. 故障排查

| 现象 | 原因 / 处理 |
|---|---|
| `bind PermissionError [WinError 10013]` | 端口被占（如 8765）。换 `--port 18765`；`netsh interface ipv4 show excludedportrange protocol=tcp` 查保留段。 |
| 录制无音频 | Playwright 只录视频。改用 OBS 录制（§5B）或后期 mux（§6）。 |
| 直播没解说声音 | OBS 浏览器源未勾「通过 OBS 控制音频」，或自动播放被拦（字幕仍显示）。 |
| `ffmpeg` 抽帧/混音报错 | Playwright 自带 ffmpeg 是精简版（仅 WebM）。`pip install imageio-ffmpeg` 提供完整版；`mux_commentary.py` 已用它自动配音。 |
| 截图 `Multiple targets ... headless` | 用 `--headless`（legacy）非 `=new`；含 `&` 的 URL 必须双引号包裹。 |
| 模型调用慢/超时 | 单步 2–10s 正常；`timeout`+合法兜底保证牌局不断；直播用 thinking 指示+解说填空。 |
| edge-tts 失败 | 网络/音色问题；该句跳过音频保留文本，或换 DashScope CosyVoice（有 DASHSCOPE_API_KEY）。 |
